# Cyber & IT forensics (CITF02)

📆 Winter 2025/26 &middot; 🧠 Documentation work &middot; ✅ Finished

Various aspects of cyber and IT forensics were covered in this course. The course was very practice-oriented: we
learned how to use [Volatility] to read volatile data, for example from RAM, and how to use [Wireshark] to extract
important data from network captures. In addition, we learned how cyber forensic experts conduct forensic
investigations and why the terms "order of volatility" and "chain of custody" are so important for IT forensic experts.

The final project was also very practice-oriented. We were asked to examine a RAM image and several Wireshark
recordings based on given questions in order to forensically investigate a real attack:
