# Development & Operation of technical measures (EBTM91)

📆 Winter 2025/26 &middot; 🧠 2 Seminar papers &middot; ✅ Finished

This course provided an introductory overview of modern cybersecurity operations and the transformation
of IT environments. It covered the planning, deployment, and daily operation of threat detection systems,
including EDR, network traffic analysis, managed detection and response, and deception technologies.

It also introduced SIEM systems and SOC playbooks, as well as the role, use cases, limitations, and future
development of next-generation firewalls. Further topics included endpoint protection, forensic use cases,
compliance requirements, and the integration of endpoint and perimeter security.

Finally, the module addressed IT transition and transformation, considering factors such as digitalisation,
sustainability, regulation, organisational change, technological progress, global connectivity, and the
challenges of integrating security-related data and event sources.
